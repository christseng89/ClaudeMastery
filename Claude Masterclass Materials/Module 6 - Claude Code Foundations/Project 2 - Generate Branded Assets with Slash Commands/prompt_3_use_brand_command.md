# Prompt 3: Use Your Brand Command

Activate the brand voice by using /my-brand


\---

## Test 1: Write a branded email

Copy and paste the following into Claude Code:

```
Context: Use /my-brand command before creating content.

Instruction: Write a follow-up email to a couple whose engagement photoshoot we just completed. Use my brand voice, colors (for any HTML formatting), and sign off with one of my brand closing phrases.

Input:
- Couple's names: Priya \\\& James
- Session: Golden hour engagement shoot at the botanical gardens
- Gallery delivery: Within 10 days
- Upsell: Mention our wedding photography packages

Output: A ready-to-send email in my brand's calm, artistic tone. Include a subject line. Create a html preview.
```

\---

## Test 2: Create a branded social media post

Copy and paste the following into Claude Code:

```
Context: Use /my-brand command before creating content.

Instruction: Write an Instagram caption for a behind-the-scenes photo from a recent wedding shoot. Use my brand voice — calm, artistic, intentional. Keep it authentic, not salesy.

Input:
- Topic: Behind-the-scenes moment — adjusting the bride's veil in soft window light
- Key message: The quiet moments between poses are where the real magic happens
- CTA: Subtle — invite people to see the full gallery (link in bio)

Output: An Instagram caption under 150 words in my brand tone. Include 5-7 relevant hashtags.

```


## Test 3: Create a branded promotional flyer

Instruction: Create a one-page promotional flyer.
Output:
Use my brand voice, tone, and visual style
Format the flyer so it can easily be recreated in Canva or PowerPoint
