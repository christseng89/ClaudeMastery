# Prompt 1: Built-in Slash Commands — Quick Tour

Slash commands are shortcuts you type directly in Claude Code. They start with `/`. Here are the ones you'll use most often:

---

## Try each of these inside Claude Code:

### See what's available
```
/help
```
> Shows all available commands.

### Check your usage and costs
```
/usage
```
> Shows how many tokens you've used and what it costs. Handy for keeping track.

### Switch models
```
/model
```
> Lets you change which AI model Claude Code uses (e.g., faster vs. smarter).

### Compact your conversation
```
/compact
```
> When your conversation gets long, this summarizes it to free up space without losing context.

### See what changed
```
/diff
```
> Shows all uncommitted file changes — useful to review what Claude just built or modified.

### Check your status
```
/status
```
> Shows your current model, account, and connection info.

---

## Key Takeaway

These are built-in — they come free with Claude Code. But the real power is when you create your **own** commands. That's what we'll do in the next prompt.
