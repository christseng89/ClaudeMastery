# 每位 SaaS 創業者都應該了解的 7 個免費開源 AI 工具

**這些工具將幫助你提升生產力，縮短開發時間。**

作者：Shivanshu Gupta｜2026 年 3 月｜閱讀時間約 4 分鐘

---

市面上有許多 AI 工具，如果你沒有善加利用，就是在白白浪費潛在的效能。 AI 已不再只是聊天工具；現在有了技能、代理人，你甚至可以將整個研究、規劃和執行工作完全自動化，交給一支 AI 團隊來處理。 因此，在今天的文章中，我將與你分享一些開源 AI 工具，幫助你更快、更有效地實現目標。

---

## #1 Agency Agents

如果你想快速組建屬於自己的代理人團隊，這個程式庫是最佳起點。它內含大量現成的代理人角色，包括資深開發者、UI/UX 設計師、資料庫工程師等等。

GitHub Repo：https://github.com/msitarzewski/agency-agents

---

## #2 Promptfoo

代理人最大的問題之一，就是確保它們使用了正確的提示詞，並給出最佳的正確結果。Promptfoo 就像是為提示詞量身打造的 A/B 測試工具。它還能幫助你識別應用程式是否容易受到提示詞注入攻擊，並提供詳細報告。

順帶一提，OpenAI 最近已收購了這個項目，所以最好趁它被下架前先將其整合到你的程式碼中。

GitHub Repo：https://github.com/promptfoo/promptfoo

---

## #3 Miro Fish

Miro Fish 是一個預測引擎，能從全球各地即時抓取資料，包括新聞、政策草案、金融訊號等等。

GitHub Repo：https://github.com/666ghj/MiroFish

---

## #4 Impeccable

這個項目能幫助你的 AI 生成真正美觀的 UI/UX 設計，而不只是隨意拼湊出來的介面。

GitHub：https://github.com/pbakaus/impeccable

---

## #5 Open Viking

這是一個開源的上下文資料庫，專為 AI 代理人而設計。它以類似檔案系統的結構來統一管理記憶、技能和資源，讓你的 AI 能在正確的情境下提供更好的輸出。

GitHub Repo：https://github.com/volcengine/OpenViking

---

## #6 Heretic

這個工具你一定會喜歡。

Heretic 是一個幫助你移除 AI 模型安全對齊限制（即「審查機制」）的項目。如你所知，代理人在執行許多操作時常常會被阻止。Heretic 將幫助你打破這道障礙。

GitHub Repo：https://github.com/p-e-w/heretic

---

## #7 nanochat

如果你想從頭開始打造自己的大型語言模型（LLM），那你一定要試試 nanochat。它涵蓋整個 LLM 流程的實作，包括分詞（tokenization）、訓練、微調（finetuning）等等。

GitHub Repo：https://github.com/karpathy/nanochat

---

10 Must-Have Skills for Claude (and Any Coding Agent) in 2026

## 10 個 Skills 簡介

文章介紹的 Skills 全部可安裝至 Claude Code，用於擴展 AI 代理人的專項能力：

## Skills 如何互補 Agency Agents 的 SDLC 缺口

### 缺口一：需求分析（Agency Agents 不足）
**✅ Google Workspace (GWS) + Antigravity (@brainstorming)**

Agency Agents 缺少正式的 Business Analyst 角色。GWS Skill 可讓 AI 自動讀取 Google Docs 中的需求文件、在 Sheets 中追蹤需求清單、將會議記錄整理成結構化需求；而 Antigravity 的 `@brainstorming` 技能則可在正式開發前進行結構化需求討論與規劃，補足這個空缺。

---

### 缺口二：系統設計與架構文件（Agency Agents 部分覆蓋）
**✅ Excalidraw Diagram Generator + Antigravity (@architecture)**

Agency Agents 雖有 Software Architect，但缺乏可交付的視覺化設計文件。Excalidraw Skill 能直接從架構討論中自動生成可分享的架構圖（API 流程、資料庫 ER 圖、微服務關係圖），Antigravity 的 `@architecture` 技能則提供系統設計的結構化規劃流程，兩者合力讓架構決策有具體的文件輸出。

---

### 缺口三：資料庫設計（Agency Agents 較弱）
**✅ PlanetScale Database Skills**

Agency Agents 的 Database Optimizer 偏向優化現有資料庫，而 PlanetScale Skill 則填補了「從零開始進行正確的 Schema 設計」這一環，包括資料庫分支管理、索引設計驗證、Schema 變更的 Code Review 流程，讓資料庫決策變得可追溯、可回滾。

---

### 缺口四：用戶驗收測試 UAT（Agency Agents 不足）
**✅ Browser Use**

Agency Agents 的測試部門偏向技術層面，缺少端對端的 UAT 自動化。Browser Use Skill 讓 AI 能真正操控瀏覽器，模擬真實用戶行為（填表、點擊、截圖、驗證流程），自動執行 Staging 環境的完整功能驗收，並截圖記錄問題，大幅填補 UAT 的空缺。

---

### 缺口五：安全測試（Agency Agents 僅有靜態審查）
**✅ Shannon**

Agency Agents 有 Security Engineer 進行程式碼審查，但沒有主動滲透測試。Shannon Skill 補上這個缺口，能在 Staging 環境自動執行真實的滲透測試（SQL 注入、XSS、SSRF、身份驗證漏洞等 50+ 類型），96.15% 的漏洞發現率，每次測試費用約 $50，相比傳統人工滲透測試節省大量時間和費用。

---

### 缺口六：技術債管理與程式碼品質（Agency Agents 不持續）
**✅ Code Reviewer (Simplify) + Antigravity (@lint-and-validate)**

Agency Agents 的 Code Reviewer 是人工觸發的角色，而 Code Reviewer Skill 則讓品質審查成為每次代碼生成後的**自動化默認步驟**，主動識別可重用的函式、違反單一職責原則的程式碼、效能問題等，持續防止技術債累積。

---

### 缺口七：交付文件與溝通（Agency Agents 不足）
**✅ Remotion + Google Workspace (GWS) + Antigravity (@doc-coauthoring)**

Agency Agents 缺少交付階段的文件整理和溝通工具。Remotion Skill 可自動生成產品 Demo 影片用於客戶驗收；GWS Skill 可自動將會議記錄、測試報告同步到 Google Docs/Drive；Antigravity 的 `@doc-coauthoring` 則協助撰寫結構化技術文件，三者合力覆蓋交付移交環節。

---

### 缺口八：即時資料與市場情報（Agency Agents 完全缺失）
**✅ Valyu**

Agency Agents 所有代理人都依賴靜態知識，無法取得最新資料。Valyu Skill 連接 36+ 即時資料來源，讓 AI 在規劃和分析時能引用最新的技術文件、競品資訊、法規要求，特別適合需要依賴實時外部資料的 SaaS 產品規劃。

# 根據前面的分析，以下是一個軟件公司應該添加的 Skills 清單，按優先級排列

---

## 第一優先：必裝（核心 SDLC 缺口）

**1. Antigravity Awesome Skills**
這是最高性價比的一個，1,234+ 個技能一次安裝，同時填補需求分析、架構設計、API 設計、文件撰寫等多個缺口。

```bash
npx antigravity-awesome-skills --claude
```

安裝後最重要的子技能：

- `@brainstorming` — 需求討論與功能規劃
- `@architecture` — 系統架構設計
- `@api-design-principles` — API 設計規範
- `@doc-coauthoring` — 技術文件撰寫
- `@create-pr` — 標準化 PR 流程
- `@security-auditor` — 安全導向代碼審查
- `@debugging-strategies` — 系統化排錯流程

---

**2. Code Reviewer (Simplify)**
讓代碼品質審查成為每次生成後的自動默認步驟，持續防止技術債累積，是維護階段最重要的補充。

```bash
npx skills add anthropics/claude-code --skill simplify
```

---

**3. Shannon（安全滲透測試）**
Agency Agents 只有靜態安全審查，Shannon 填補主動滲透測試這個關鍵缺口，建議在每次部署 Staging 前執行。

```bash
npx skills add unicodeveloper/shannon
```

---

## 第二優先：強烈建議（提升交付品質）

**4. Browser Use**
填補 UAT 缺口，讓 AI 能真正模擬用戶操作瀏覽器、自動執行端對端驗收測試並截圖記錄，不再依賴人工手動測試。

```bash
npx skills add https://github.com/browser-use/browser-use --skill browser-use
```

---

**5. Excalidraw Diagram Generator**
填補架構文件缺口，讓每個系統設計決策都有可交付的視覺架構圖，對客戶交付和團隊溝通尤其重要。

```bash
npx skills add https://github.com/coleam00/excalidraw-diagram-skill --skill excalidraw-diagram
```

---

**6. Google Workspace (GWS)**
填補需求收集和交付文件管理缺口，讓 AI 能自動讀寫 Google Docs 需求文件、Sheets 項目追蹤表、自動發送 Gmail 交付通知，適合已使用 Google Workspace 的團隊。

```bash
npm install -g @googleworkspace/cli
gws mcp -s drive,gmail,docs,sheets,calendar
```

---

## 第三優先：視項目需要

**7. PlanetScale Database Skills**
若公司使用 MySQL/PostgreSQL，此技能讓資料庫 Schema 設計更嚴謹，變更有版本管理和 Code Review 流程。

```bash
brew install planetscale/tap/pscale
npx skills add planetscale/database-skills
```

---

**8. Valyu**
若產品需要依賴實時外部資料（市場資料、法規文件、競品分析），才需要安裝。一般純軟件開發項目優先級較低。

```bash
npx skills add https://github.com/valyuai/skills --skill valyu-best-practices
```

| 優先級 | Skill | 主要填補的 SDLC 缺口 |
|---|---|---|
| 🔴 必裝 | Antigravity Awesome Skills | 需求分析、架構設計、API 設計、文件 |
| 🔴 必裝 | Code Reviewer | 代碼品質、技術債管理 |
| 🔴 必裝 | Shannon | 安全滲透測試、部署前驗證 |
| 🟡 建議 | Browser Use | UAT、端對端自動化測試 |
| 🟡 建議 | Excalidraw | 架構文件、交付圖表 |

最快的起步方式是先裝 **Antigravity + Code Reviewer + Shannon** 這三個，已能覆蓋最關鍵的缺口，之後再按項目需求逐步添加其餘技能。
